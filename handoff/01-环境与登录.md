## 3. 编译

### 3.1 环境变量（每次新 shell 都要设）

```bash
source /media/a100/data/zbw/nasctime/omnetpp-6.4.0/setenv
export LD_LIBRARY_PATH=/media/a100/data/zbw/conda-envs/nasctime/lib:/media/a100/data/zbw/nasctime/omnetpp-6.4.0/lib
export INET_ROOT=/media/a100/data/zbw/nasctime/inet
export SIMU5G_ROOT=/media/a100/data/zbw/nasctime/Simu5G
```

> **坑**：`LD_LIBRARY_PATH` 里的 conda 路径必须是 `/media/a100/data/zbw/conda-envs/nasctime`，
> 写成 `zbw/nasctime/conda-envs` 会导致 `libQt6Core.so.6: version 'Qt_6.11' not found`。

### 3.2 Simu5G（改过 GtpUser，需要时重编）

```bash
cd /media/a100/data/zbw/nasctime/Simu5G/src

```

产物：`Simu5G/out/gcc-release/src/libsimu5g.so`

### 3.3 nascTime

```bash
cd /media/a100/data/zbw/nasctime/nascTime

```

> INET 一般不用重编（未改动）。

## 4. 跑一个场景

统一入口是 `nascTime/bin/nasctime-run.sh`：

```bash
cd /media/a100/data/zbw/nasctime/nascTime/simulations/demos/<场景目录>
../../../bin/nasctime-run.sh -f omnetpp.ini -u Cmdenv -c <配置名> -r 0 \
    --sim-time-limit=2s --result-dir=results_<名字>
```

示例（日字形三切片，TAS 配置）：

```bash
cd /media/a100/data/zbw/nasctime/nascTime/simulations/demos/t2_ladder
../../../bin/nasctime-run.sh -f omnetpp.ini -u Cmdenv -c TAS -r 0 \
    --sim-time-limit=2s --result-dir=results_TAS
```

结果在 `results_TAS/*.sca`。

### 常用命令行覆盖

```bash
# 改某个参数
--*.client1.app[0].sendInterval=200us

# 关闭门控（对照）
--*.pe*.eth[*].macLayer.queue.hasGcl=false

# 关掉向量记录，加快速度、减小文件
--**.vector-recording=false
```

## 6. Git 与推送

提交用统一脚本（会自动排除本地临时文件）：



```powershell

git fetch "C:\Users\a\.dsh\remote-workspaces\wmv4mdfl29ql5\exports\nasctime-repo.bundle" main
```

## 7. 环境类踩坑清单

| 现象 | 原因 | 处理 |
|---|---|---|
| `Qt_6.11 not found` | `LD_LIBRARY_PATH` 里的 conda 路径写错 | 用 `/media/a100/data/zbw/conda-envs/nasctime/lib` |
| `Unknown protocol: protocolId = 34` | RSTP 的 BPDU 到达无 LLC 的端节点 | 不要在这些拓扑开 STP，见 04 文档 |
| `Connected network interfaces can register using registerInterface()` | 同一接口被两个协议栈注册 | 检查 TSN 是否接到了 `upf.pppg`（N3）而不是 `dnPppg`（N6） |
| `Object nullptr has no member named 'destPort'` | 表达式分类器遇到非 UDP 报文（ARP / IP 分片） | `**.arp.typename="GlobalArp"` + UDP 载荷 ≤1472 B |
| `The duration parameter must contain an even number of values` | `PeriodicGate.durations` 必须是成对出现 | 三相窗口改用 `GateControlList` |
| 仿真跑出 1 个包就停 | 流量全部落到关闭的队列等级 | 先查各队列 `incomingPackets:count` |
